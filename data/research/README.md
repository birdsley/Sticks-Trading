# data/research

Static data for the dashboard's Research tab, generated by a private script from the project's research results and refreshed by hand.

- `index.json` — ledger rows (one per study), funnel counts, headline numbers and data vintages
- `studies/<id>.json` — one study: question, method, metrics tables, verdict, lessons, vintage
- `trials.json` — every gate-tested configuration (sensitivity runs excluded, except v43's seven, which were pre-registered as trials)
- `case_studies/*.json` — featured long-form panels (flagship includes the Monte Carlo histogram)
- `methods.json` — Methods, Why most strategies didn't work, glossary
- `strategies.json` — every strategy on the main chart: name, description, group, metrics
- `mc/<id>.json` — block-bootstrap Monte Carlo per strategy (2,000 resampled histories): equity fan, sample paths, Sharpe histogram
- `curves/*.csv` — weekly (Friday) equity curves, each series rebased to 100 (`strategies.csv` feeds the main chart)

Fractions are decimals (−0.12 = −12%). Sharpe ratios are annualised with rf = 0. Research code is private; methods are summarised on the page.
